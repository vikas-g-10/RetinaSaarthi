# Objective 3: exploratory lesion overlap protocol

Recorded before calculating overlap results. The unit is one mapped segmentation-training / grading-testing image pair. Include only the three confident mappings 09/091, 22/088 and 31/089 with grade 2, existing image files, matching dimensions, and at least one nonempty lesion mask. They are candidate held-out images, not proven independent: the checkpoint does not identify its training manifest; the current manifest and duplicate audit cannot rule out other overlap or patient leakage. No model training or tuning is performed.

Use the grading test photo as model input with the existing evaluation transform (224×224 resize, tensor, ImageNet normalization). Explain the predicted class using Grad-CAM at EfficientNet-B0 `features[-1]`, with ReLU, bilinear upsampling to 224×224, and per-image min-max normalization as in the existing script. A constant map becomes zero. Fix the binary cutoff at normalized activation >= 0.5, an arbitrary prespecified midpoint, not a clinically optimized threshold. Upsample the continuous map bilinearly to the original photograph dimensions before thresholding. Do not apply registration: all three pairs have identical dimensions, zero reduced-resolution mapping shift, and original-resolution local patch checks around microaneurysms support zero displacement. This is not exhaustive proof of alignment.

Use the union of available microaneurysm, haemorrhage, hard-exudate, and soft-exudate binary masks at native resolution; exclude optic disc. Validate dimensions and pixel values. Missing masks are unknown, never negative labels: report 09 separately as incomplete; do not combine its overlap with the complete-file subset. Even complete file availability does not establish exhaustive annotation. An empty union is excluded with an explicit reason; no available masks is an error. A nonempty union with an empty activation has zero IoU, Dice, and coverage. Define intersection I, activation area A, recorded lesion area L: IoU = I/(A+L-I), Dice = 2I/(A+L), lesion coverage = I/L. Report each image and the unweighted mean of the two complete-file images; no confidence interval or generalization from this sample.

This measures overlap with recorded pixels, not whether explanations are clinically correct. Threshold, small lesions, resolution, model prediction, and annotation completeness affect results. A prospective independent dataset, documented checkpoint provenance, patient-level leakage assessment, alignment review, and prespecified threshold sensitivity analysis remain necessary.
